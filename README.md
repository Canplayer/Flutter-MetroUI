# Flutter Metro UI

面向 Flutter 的 Windows Phone 风格控件与页面框架，包含系统版本预设、主题、页面导航、Application Bar、Pivot、Panorama 和常用控件。`MetroApp` 默认使用 WP8 预设，用于整套应用。`MetroTheme` 可单独应用到普通 Flutter 应用的子树。

- [技术规范](TECHNICAL_SPEC.md) 介绍框架结构、控件用法、文字排版、WP 资源换算和验收流程。
- [系统版本与主题接入](THEME_ARCHITECTURE.md) 描述局部预设、主题扩展及跨版本动画配置。

本仓库的 `.fvmrc` 指定开发使用的 Flutter 版本。运行 `flutter test` 验证控件与页面行为。
